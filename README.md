## Ejercicio 2 - Calculadora
Calculadora de consola en Node.js: suma, resta, multiplicación y división entre dos números, con menú interactivo.

### Cómo correrlo
cd Ejercicio2
node calculadora.js

## Ejercicio 3 - ToDo List
App de consola en Node.js para gestionar tareas diarias: crear, ver, buscar, filtrar por estado y editar.

### Cómo correrlo
cd Ejercicio3
node tp1.js

### Estructura
- tp1.js: menú principal e interacción con el usuario
- tareas.js: creación y almacenamiento de tareas
- Mostrar.js: visualización de tareas y detalles
